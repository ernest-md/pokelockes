Fuego, Planta y Agua. Tres diarios independientes, tres aventuras por Paldea, Noroteo y el Biodomo. Entra en tu run y registra cada captura, victoria y baja.

¿Cómo funciona el resumen?

Los contadores muestran el progreso guardado en este navegador. Si tus amigos actualizan sus runs desde otros móviles, sus estadísticas no aparecerán aquí automáticamente. GitHub Pages publica la web, pero no guarda ni sincroniza las partidas. Cada jugador puede exportar su JSON para conservar o trasladar sus datos.
